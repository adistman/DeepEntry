# Data Archive

The companion archive contains:

- curated training pairs;
- CRISPR/siRNA host-factor overlap tables;
- virus-level interaction tables;
- complete 38-fold receptor-ranker checkpoints for the deposited public benchmark protocols;
- per-fold benchmark outputs for leave-one-virus, controlled dynamic-prior, leave-family-out and leave-genus-out analyses;
- manuscript figure PDFs;
- benchmark and diagnostic result tables.

The checkpoint and per-fold result directories use public protocol names and omit internal experiment labels and local filesystem paths. Use the result tables for manuscript verification and use the scripts in this repository to validate file presence and headline metrics.
