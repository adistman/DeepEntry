# Data Archive

The companion archive contains:

- curated training pairs;
- CRISPR/siRNA host-factor overlap tables;
- virus-level interaction tables;
- selected receptor-ranker checkpoints;
- manuscript figure PDFs;
- benchmark and diagnostic result tables.

The model checkpoints are selected fold examples unless a complete checkpoint set is explicitly deposited. Use the result tables for manuscript verification and use the scripts in this repository to validate file presence and headline metrics.
